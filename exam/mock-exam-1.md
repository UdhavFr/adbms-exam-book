## Section A — 2-mark questions (10 × 2 = 20)

**A1.** Define *database* and *DBMS*.
**A2.** What is the difference between a schema and an instance?
**A3.** Define *functional dependency*.
**A4.** State the defining condition of First Normal Form.
**A5.** What does ACID stand for?
**A6.** Define a *transaction*.
**A7.** State the CAP theorem in one sentence.
**A8.** What is sharding?
**A9.** Define *embedding* in the context of vector databases.
**A10.** What is an index?

## Section B — 5-mark questions (8 × 5 = 40)

**B1.** Distinguish physical data independence from logical data independence, giving an example of each.
**B2.** List and explain the six types of attributes in the ER model.
**B3.** Compare super key, candidate key, primary key, alternate key and foreign key.
**B4.** Explain the three modification anomalies with one example each.
**B5.** State the four SQL command categories with two commands in each category.
**B6.** Compare 3NF and BCNF.
**B7.** Compare deferred update and immediate update.
**B8.** Compare HBase and Cassandra on four points.

## Section C — 10-mark questions (3 × 10 = 30)

**C1.** Explain the three-level architecture with a labelled diagram, and distinguish physical from logical data independence with examples.
**C2.** Define a transaction and explain ACID with a bank-transfer example for each property. Then list the four isolation levels.
**C3.** Explain B+ tree indexing with a diagram and compare it with hash indexing. Which would you use for a range query and why?

## Section D — 20-mark question (1 × 20 = 20)

**D1.** Explain normalization and all normal forms, up to and including 5NF. Include functional dependencies, attribute closure, the lossless-join property and dependency preservation in your answer.
