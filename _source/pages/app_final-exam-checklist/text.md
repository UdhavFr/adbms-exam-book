## FINAL EXAM CHECKLIST
_(p. 36)_
- Read the question twice and identify exactly what is being asked.
- Write the definition first.
- Use headings for every major concept.
- Draw the relevant diagram before or during the explanation.
- For normalization, show dependencies and decomposition.
- For transactions, use ACID + schedule + control + recovery.
- For distributed systems, use fragmentation + replication + CAP + sharding.
- For MongoDB/Cassandra/Redis/Neo4j, include actual commands.
- For indexing, explain both performance benefit and maintenance cost.
- End with a conclusion.
- Do not stop after 2–3 pages if the question asks for a complete 20-mark explanation; use the full structure.
