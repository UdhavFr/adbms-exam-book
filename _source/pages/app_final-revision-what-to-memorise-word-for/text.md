## FINAL REVISION: WHAT TO MEMORISE WORD-FOR-WORD
_(p. 35)_
Definitions should be memorised accurately, while examples and explanations should be understood so they can be adapted to the question.

| Topic | Core sentence to remember |
|---|---|
| DBMS | A DBMS is software that provides facilities for defining, storing, retrieving, updating, securing and recovering data in a database. |
| Functional dependency | X → Y means that the value of X uniquely determines the value of Y. |
| 1NF | A relation is in 1NF when attributes contain atomic values and repeating groups are removed. |
| 2NF | A relation in 1NF is in 2NF when every non-prime attribute is fully dependent on the whole candidate key. |
| 3NF | A relation is in 3NF when for every non-trivial X → A, X is a super key or A is a prime attribute. |
| BCNF | A relation is in BCNF when every determinant of a non-trivial functional dependency is a super key. |
| 4NF | A relation is in 4NF when every non-trivial multivalued dependency has a super key as its determinant. |
| 5NF | A relation is in 5NF when every non-trivial join dependency is implied by candidate keys. |
| Lossless join | A decomposition is lossless when joining its decomposed relations reconstructs exactly the original relation. |
| Transaction | A transaction is a logical unit of database work that must preserve correctness. |
| ACID | ACID stands for Atomicity, Consistency, Isolation and Durability. |
| Serializability | A schedule is serializable when its effect is equivalent to some serial execution of the transactions. |
| 2PL | Two-phase locking has a growing phase for acquiring locks and a shrinking phase for releasing locks. |
| CAP | During a network partition, a distributed system cannot simultaneously guarantee both strong consistency and availability for every request under the CAP definitions. |
| Sharding | Sharding horizontally partitions data across multiple nodes. |
| NoSQL | NoSQL is a broad family of non-relational database technologies designed for flexible data models and scalable/distributed workloads. |
| Embedding | An embedding is a numerical vector representation of an object produced by an embedding model. |
| Vector similarity search | Vector similarity search retrieves stored vectors closest to a query vector according to a chosen similarity or distance measure. |
| Index | An index is an auxiliary access structure that improves data lookup performance at the cost of storage and maintenance. |
