### 6. NoSQL Systems — Types
_(p. 23)_
NoSQL databases are non-relational data-management systems designed for use cases such as flexible schemas, massive scale, high throughput, distributed availability, or relationship patterns that differ from traditional tables.

| Type | Data representation | Typical applications |
|---|---|---|
| Document | JSON/BSON-like documents | Catalogs, content, profiles |
| Key-value | Key → value | Cache, sessions, simple lookups |
| Column-family | Partitioned rows + flexible columns | Large-scale distributed workloads |
| Graph | Nodes + relationships + properties | Social networks, recommendations, fraud relationships |
