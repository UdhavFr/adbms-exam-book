# ADBMS Exam Quest

## Scope
Interactive conversion of `ADBMS_MasterNotes.docx` into a static Papermorph-style exam book.

## Audience
Student with an exam tomorrow morning; bored attention, high urgency.

## Goal
Maximize exam marks via active recall, 20-mark answer structures, diagrams, exact anchor definitions, memory hooks and mini-boss checks.

## Conventions
- 1600×900 SVG lesson stage.
- Each chapter is a beat sequence with a diagram, explanation and optional memory/trap callout.
- Every chapter ends with multiple-choice mini-boss practice.
- Browser speech synthesis is available as a local narration fallback.
- Source material is not copied into the static site; it is transformed into concise exam-ready lessons.
- Do not silently introduce external facts; this book uses the supplied notebook’s terminology and framing.
